# ส่งออก JSON และเปิดใน Google Sheets

ระบบส่งออกสองรูปแบบจากผลตรวจรอบเดียวกัน ไม่มี CSV และไม่ต้องตั้งค่า API key, OAuth หรือ Apps Script

- **JSON** เก็บโครงสร้างข้อมูลและหลักฐานต้นฉบับ เหมาะสำหรับเก็บไว้ตรวจต่อหรือใช้งานกับโค้ด
- **XLSX** แปลงข้อมูลที่อ่านในตารางเป็น workbook สำหรับ Google Sheets ไม่ใช่การเปลี่ยนนามสกุลของ JSON

## ดาวน์โหลด

ข้างหัวข้อ **ภาพรวมการตรวจ** มีปุ่ม JSON และ Google Sheets (.xlsx) สำหรับรายงานทั้งรอบ
ข้างหัวข้อ **ปัญหาที่พบ** มีปุ่ม JSON และ XLSX สำหรับรายการปัญหาตามตัวกรองปัจจุบัน
มุมมองรวมตามประเภทส่งออกสมาชิกแต่ละปัญหาและ URL ที่เกี่ยวข้อง ไม่ลดเหลือแถวสรุปจนหลักฐานหาย
ปุ่มส่งออกรายงานทั้งรอบยังใช้ได้เมื่อไม่พบปัญหา ส่วนปุ่มปัญหาปิดเมื่อไม่มีรายการตรงตัวกรอง
ดาวน์โหลดแต่ละไฟล์แยกกัน ไม่มีการดาวน์โหลดหลายไฟล์อัตโนมัติ

## เปิดใน Google Sheets

1. ดาวน์โหลด `.xlsx` จากปุ่ม Google Sheets หรือ XLSX
2. เปิด Google Sheets แล้วสร้างชีตใหม่
3. เลือก **File > Import > Upload** แล้วเลือกไฟล์ `.xlsx`
4. เลือก **Create new spreadsheet** หรือ **Insert new sheet(s)** แล้วกด **Import data**

อีกทางหนึ่งคืออัปโหลด `.xlsx` ไป Google Drive แล้วเลือก **Open with Google Sheets**
ขั้นตอนนี้ผู้ใช้อัปโหลดเองในบัญชี Google ของตน ระบบ checker ไม่ส่งหรือเก็บสำเนาใน Google
อ้างอิง: [Google: Import Excel data into Sheets](https://support.google.com/docs/answer/9331167?hl=en)

JSON เปิดเป็นตารางใน Google Sheets โดยตรงไม่ได้ ใช้ JSON เป็นข้อมูลต้นฉบับและ XLSX เป็นฉบับตารางคู่กัน
ยังไม่ได้ทดสอบการอัปโหลดในบัญชี Google จริง; ทดสอบสร้าง/อ่าน workbook และค่าทุกตารางกลับด้วย ExcelJS แล้ว

## ตารางใน XLSX

- `Summary`: URL เวลา ขอบเขต ตัวกรอง สถานะ จำนวน และข้อจำกัดจริง รวม provider, network และ limitations ของ Lighthouse
- `Pages`: HTTP สถานะตรวจ title description canonical และกฎ Googlebot ของหน้าที่อ่านสำเร็จ
- `Issues`: ปัญหาแต่ละรายการ พร้อมความสำคัญ ผลที่พบ ผลกระทบ วิธีแก้ และ references
- `Issue URLs`: URL ที่ได้รับผลกระทบแต่ละรายการ เชื่อมด้วย Issue ID
- `Evidence`: หลักฐานของแต่ละปัญหา พร้อม source URL ตำแหน่ง และรายละเอียด JSON
- `Scores`: คะแนน Lighthouse ในเครื่อง พร้อม URL, โหมด และ engine version ไม่สร้างคะแนนแทนข้อมูลที่ไม่มี และไม่เฉลี่ยข้ามหน้า
- `Not Checked`, `Discovered`, `Skipped`: สิ่งที่ยังตรวจไม่ได้ URL ที่พบ และเหตุผลที่ข้าม

XLSX ของปัญหาที่กรองมีเฉพาะ Summary, Issues, Issue URLs และ Evidence; Summary ระบุจำนวนที่เลือกแยกจากยอดทั้งรอบ
XLSX ไม่บรรจุ HTML ทั้งเอกสารหรือ DOM snapshot ฉบับเต็มลงเซลล์ ให้ดูข้อมูลส่วนนี้จาก JSON
แท็บ `Long Text` จะเพิ่มเฉพาะเมื่อข้อความยาวเกินเซลล์ แยกข้อมูลเป็นส่วนย่อยในคอลัมน์ `Text JSON`
สามารถ `JSON.parse()` แต่ละส่วนแล้วต่อข้อความตาม Sheet, Cell และ Part กลับได้ โดยไม่ตัดข้อความเงียบ ๆ

## ความปลอดภัยและขอบเขต

ใช้ ExcelJS 4.4.0 ที่ตรึงเวอร์ชันบน CDN สร้าง workbook ใน RAM ของ browser เมื่อกดดาวน์โหลดเท่านั้น
โหลด library พร้อม Subresource Integrity; ถ้าไฟล์ CDN ไม่ตรงกับ hash ที่กำหนด browser จะไม่รันไฟล์นั้น
ไม่มี endpoint ส่งออก ไม่มีไฟล์ temporary/report ที่ backend และไม่ใช้ browser storage เก็บรายงาน
F5 หรือปิดหน้าเว็บล้างผลในแอป แต่ไม่ลบไฟล์ที่ผู้ใช้ดาวน์โหลดหรืออัปโหลดไป Sheets ด้วยตนเอง
การตรวจรอบใหม่ไม่ให้ XLSX ของรอบเก่าที่กำลังสร้างดาวน์โหลดตามมาทีหลัง

XLSX เขียนค่าข้อความเป็น literal และเติม apostrophe ให้ข้อความที่เริ่มเหมือนสูตร โดยไม่แก้ JSON ต้นฉบับ
อักขระที่ใช้ใน XML ไม่ได้แสดงเป็น escape ข้อความ ไม่มี formulas, macros หรือ hyperlinks ที่รันจากข้อมูลเว็บไซต์
workbook จำกัด 1,000,000 cells, 100,000 rows ต่อแท็บ และ 30,000 characters ต่อเซลล์เพื่อควบคุม RAM
ถ้าใหญ่เกินขอบเขตหรือโหลด library ไม่ได้ จะไม่ดาวน์โหลดไฟล์เสีย และยังดาวน์โหลด JSON ได้ตามปกติ
